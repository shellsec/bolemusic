# Switch 播客频道展示

## 播客首页

顶部为继续收听、我的订阅、发现节目、已下载四个标签，ZL/ZR 切换。分类采用纵向列表，节目采用两列封面卡。每张卡显示节目名称、短简介、语言、最近更新时间与未听数量。列表按焦点滚动，返回时恢复位置。

继续收听卡优先显示单集名称、剩余时长及进度。发现依次优先学习成长、经济商业、科技知识、人文视野，故事与游戏娱乐靠后。默认顺序由远程目录维护，用户可以切换排序。

## 节目频道

左侧为封面、节目名称、发布者、简介与订阅按钮。右侧为单集列表，显示标题、日期、时长、剩余时间以及下载/已听状态。提供全部、未听、进行中、已下载筛选和新旧排序。A 打开单集操作，Y 节目设置，B 返回。

单集操作包含继续/从头播放、下载/取消/删除下载、加入待播、标记已听/未听、书签和节目说明。破坏性操作再次确认。

## 播放

显示实际播放时间和总时长、倍速、章节、书签与定时停止。X 播放暂停，L 后退15秒，R 前进30秒，Y 单集操作，B 返回且继续播放。暂停和退出保存本地断点，休眠后恢复同一集。

## 电台

精选、热门、全部、收藏、自定义保留清楚入口。卡片显示台名、类型、地区、格式与连接状态。实时直播没有单集下载或播放进度。
